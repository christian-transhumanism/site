## Notes for whoever maintains this

- Slugs become the live URL: `/topics/<slug>/`. Keep them short, hyphenated, stable.
- One page = one clear audience lead. A topic can appear twice with different slugs if
  it genuinely deserves a CC version and an SR version, but don't split casually.
- When adding an idea, name at least one `cta-wiki` anchor note so the research step
  has a starting thread.
